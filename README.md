# M-app · M-PACK prototype

A warm, bright web app for teachers, counselors, program staff, and parents to
notice how a child is doing, track fight / flight / freeze / regulated moments
over 9-week cycles, and act early with supportive, strengths-first ideas.

Prototype only. Demo seed data, no login, a role switcher in the header.

## Run locally

```bash
npm install
cp .env.example .env.local   # optional, enables live AI suggestions
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Without `ANTHROPIC_API_KEY` set, the Suggest panel returns a built-in fallback
set of ideas so the UI demos end-to-end.

## Deploy on Vercel

1. Push to a Git provider and import the repo into Vercel.
2. Framework preset: Next.js (auto-detected).
3. Add `ANTHROPIC_API_KEY` in Project Settings → Environment Variables for
   Production and Preview.
4. Deploy.

## Decisions baked in (per PRD §3b)

- Role switcher in the header, no login
- ACE score shown on profiles (hidden for Teacher and Parent views)
- Interventions generated by Claude Sonnet 5.5 with strengths-first guardrails
- Deployed via Vercel default Next.js preset

## Privacy & safety notes

- Standing banner: "Demo data · do not enter real student info"
- Role-based ACE visibility: Teacher and Parent views hide it
- AI route sends only de-identified data (age band, group, counts, contexts,
  strengths). Never names. Server-side key only.
- System prompt forbids diagnosis, labels, medication, and punishment framing.
- Before a real pilot M-PACK should complete FERPA review, parental consent,
  IRB review (if data is shared for research), and a retention policy.
